# 我的日程置顶：门户「我的日程」复刻到 Notion Hub 顶部

> 日期：2026-08-20 ｜ 来源：Edge 抓取门户 + 本科教务管理系统「作息时间」模块 ｜ 关联：change-history/2026-08-20-notion-schedule-top

## 背景

用户在门户首页右侧发现「我的日程」组件：周条（周日~周六 + 今天高亮）+ 事件卡片（时间区间 / 课程名 / 地点 / 来源标签），非常美观实用，要求把「每一天要上的课（时间·名字·地点）」复刻到 Hub 页最开头。当前是暑假（第 25 周），门户只显示 3 条重复的"已过期"事件（2026-06-30 中国近现代史纲要 建筑A302）。

## 关键事实

- 门户「我的日程」= 教务课表镜像（个人日历源）；事件时间与教务课表节次存在一处偏差（门户显示 08:30-09:15，教务课表为第二节），以官方作息时间为准。
- 官方作息时间（本科教务管理系统 → 首页「作息时间」，2026-08-20 抓取，浑南校区 12 节）：
  第1节 08:30-09:15、第2节 09:25-10:10、第3节 10:30-11:15、第4节 11:25-12:10、
  第5节 14:00-14:45、第6节 14:55-15:40、第7节 16:00-16:45、第8节 16:55-17:40、
  第9节 18:30-19:15、第10节 19:25-20:10、第11节 20:20-21:05、第12节 21:15-22:00。
- 门户「教学周」按周日~周六（第25周=08-16~08-22）；教务课表「周次」按周一起始对齐校历（第1周=2026-03-02 起）。周次→日期换算以校历库为准。
- 门户「更多」打开的完整日程站是 Nuxt SSR 空壳（body 无内容），无 API 可挖；数据以教务课表（34 行）+ 校历（25 周）为源，无需门户接口。

## 做了什么

1. 新建「我的日程」内嵌数据库（Hub 第一个块）：列 = 课程(title) / 星期 / 节次 / 开始时间 / 结束时间 / 地点 / 教师 / 周次 / 学期 / 状态 / 来源 / 备注，34 行 = 课程表 34 行 + 官方节次时间换算（跨节次取首末节，如"第五节起4节"= 14:00-17:40）。
2. 全量重建 Hub（13 库）：删除全部块 → 按新顺序建库（我的日程排第一）→ 补 relation（data_sources PATCH）→ 灌行 → position:start 插入顶部区块（📅 我的日程 h1 + 教学周 callout）→ after_block 插 🧭/今日聚焦/学习管理 → 各分区标题。
3. 默认视图排序修正：新库默认视图按"创建倒序"显示，34 行先删后按目标显示顺序的逆序重建，最终默认视图 = 周一→周日、时间升序。
4. 列顺序修正（视图级，API 不可控）：Edge UI 操作「设置 → 属性是否可见」面板，逐行拖拽把手，最终列序 = 课程/星期/开始时间/结束时间/节次/地点/教师/周次/学期/状态/来源/备注。
5. 顶部 callout 更新：🧭 分区清单加入"我的日程"；⭐ 今日聚焦 callout 标注"我的日程已上线（2026-08-20）"。
