- 本地 sparse 克隆（wsl-src-master-sparse）拉取 tag 2.7.8/2.7.12/2.9.3/2.9.4/2.9.5/2.9.6/2.9.7。

  - PR 41125（listen 隐式 autobind 追踪）：merge 96b220c7，仅 2.9.5+ 含。
