# 升级与回滚

- 变更日期：2026-08-16
- 关联问题：Refs #11

## 升级方式

- 无数据库迁移、无 CRD 变化、无 Schema 变化：直接更新代码并重新运行 `bash setup.sh` 即可。
- 只影响本机启动脚本 `hack/local-cluster.sh` 与相关脚本执行位，不影响集群内已有工作负载。

## 回滚方式

- `git revert` 关联提交即可：`1f7b987`（并行构建与跳过拉取）、`2885f1e`（端口转发存活检查）。
- 回滚后 `bash setup.sh` 回到串行构建 + 无条件拉取 + 旧存活检查行为；已部署的工作负载不受影响。

## 风险与注意事项

- 并行构建下日志交错属预期现象，判断失败以退出码为准。
- 端口探测使用 bash `/dev/tcp`，需要 bash 3+；脚本已要求 `/usr/bin/env bash`，低版本 bash 环境需留意。
- 若用户机器上存在手工创建的转发进程且与 PID 文件不一致，新的端口探测会重建转发，属预期收敛行为。
