## 踩过的坑（重要，后续别重踩）

- **PowerShell 调 WSL**：bash heredoc 会被 PowerShell 双引号插值破坏（`$`、`"`、`${}` 都会被吞）。可靠方式：PowerShell `@'...'@` here-string 写 `$env:TEMP\` 下文件 → `wsl cp` 进仓库；或用 python 脚本文件（同样经 temp 传入）做字符串替换。**不要用 `wsl -lc "bash heredoc"`**。
- **fake client status 子资源**：任何 `Status().Update/Patch` 的 CRD 测试必须 `WithStatusSubresource(...)`，否则 NotFound。
- **docs-check 门禁**（CI 的 push 事件用 `HEAD~1` 当 base，pull_request 用 `origin/main`）：
  - MAP 门禁：源码改动必须同步 `docs/MAP.yaml` 映射的文档（如 `hack/` → DEPLOYMENT/TROUBLESHOOTING）。

  - 改了 docs 记得 `make docs-sync`（生成 README 时间线段/docs/status.md/llms.txt）。
